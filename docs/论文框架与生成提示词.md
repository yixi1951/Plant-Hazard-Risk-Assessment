### 摘要（200–300 字）

> **模板**：农作物病害是影响农业生产的重要因素，传统人工诊断方式存在效率低、主观性强等局限。本文构建了一套基于多任务深度学习的农作物病害智能诊断系统。以 MobileNetV2 为骨干网络，创新性地引入跨任务注意力机制，实现病害类别识别与严重程度分级的联合学习。在 PlantVillage 数据集上，系统 Top-1 准确率达到 74.7%，宏平均 F1 为 0.70，严重程度分级准确率超过 85%。同时，开发了基于 Flask 的 Web 诊断系统，支持图像上传、实时诊断、Grad-CAM 可解释性分析和诊断报告生成，并支持 Docker 容器化部署。实验结果表明，多任务学习相比单任务模型具有显著的协同增益，验证了本系统在农业病害智能诊断领域的应用价值。

### 第 2 章 相关技术与理论基础 — 约 400 字

#### 2.1 卷积神经网络基础
- CNN 核心组件：卷积层（特征提取）、池化层（降采样）、全连接层（分类决策）
- 迁移学习与预训练模型原理：在 ImageNet 上预训练的模型可通过微调适配目标任务

#### 2.2 多任务学习理论
- **定义**：在共享骨干网络基础上同时学习多个相关任务
- **优势**：利用任务间的共享表示提升泛化能力，降低过拟合风险
- **硬参数共享机制**：共享底层特征提取层，各任务保有独立输出头

#### 2.3 可解释性 AI 技术
- Grad-CAM 热力图可视化原理：利用梯度加权类激活映射定位模型决策的关键区域
- 在农业病害诊断中，Grad-CAM 可展示模型关注的叶片区域，辅助验证诊断可靠性

#### 2.4 Flask Web 开发技术
- 轻量级 Python Web 框架，适合快速搭建 AI 模型推理服务
- 前后端交互原理：前端上传图像 → Flask 路由接收 → 模型推理 → 结果渲染

### 第 3 章 数据集构建与预处理（对应"数据介绍及处理"15 分）— 约 600 字

#### 3.1 数据集来源与特点
- **PlantVillage 公开数据集**：61 类病害 + 健康叶片，5 万+张图像
- 数据集类别分布与统计信息（类别间样本量不均衡，部分稀有病害样本较少）
- **模拟数据集生成**：项目提供 `scripts/generate_mock_dataset.py`，用于快速验证与课堂演示

#### 3.2 数据预处理流程
- **图像尺寸统一**：所有图像 Resize 至 128×128×3（平衡推理速度与识别精度）
- **像素值归一化**：ToTensor 转为 [0,1] 后，以 ImageNet 均值和标准差标准化
  ```python
  transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
  ```
- **数据增强**：随机水平翻转、随机旋转（±10°）、亮度调整、随机裁剪
- **数据集划分**：训练集 : 验证集 = 8 : 2

#### 3.3 数据质量分析
- **类别不平衡问题**：采用 Focal Loss 与类别加权交叉熵缓解
- **严重程度标签推导**：依据病害名称中的关键词（如"严重"、"一般"、"健康"）自动生成严重程度标签（函数 `disease_to_severity()`）
- 异常图像处理：加载失败时使用黑色占位图替代

### 第 4 章 多任务病害诊断模型设计与实现（对应"模型实现"30 分，核心章节）— 约 1200 字

> 本章是论文得分关键，必须详细阐述模型设计思路与实现细节。

#### 4.1 整体模型架构设计
```
输入图像 (128×128×3)
        ↓
  ┌─────────────────┐
  │  MobileNetV2骨干  │  预训练权重，冻结前 N-3 层
  └────────┬────────┘
           ↓  (batch, 1280, 4, 4)
  ┌─────────────────┐
  │  全局平均池化层    │  AdaptiveAvgPool2d
  └────────┬────────┘
           ↓  (batch, 1280)
  ┌──────────────────────────────┐
  │    跨任务注意力模块(CrossTask) │  病害查询 + 严重程度查询
  └────┬────────────────────┬────┘
       ↓                    ↓
  ┌──────────┐      ┌──────────────┐
  │病害分类头  │      │ 严重程度分级头  │
  │61类Softmax│      │ 3级Softmax    │
  └──────────┘      └──────────────┘
       ↓                    ↓
   病害类别              严重程度 → 风险评分
```

#### 4.2 骨干网络选择 — MobileNetV2
- **原理**：使用深度可分离卷积（Depthwise Separable Convolution）和倒残差结构（Inverted Residual），大幅降低参数量和计算量
- **优势**：
  - 轻量高效：仅约 3.5M 参数，适合边缘设备部署
  - 高精度：在 ImageNet 上达到与 VGG16 相当的精度，但计算量仅为其 1/30
  - 本项目冻结前 N-3 层，仅训练最后 3 层（迁移学习微调策略）
- 总参数量约 3.5M，可训练参数量约 0.8M

#### 4.3 跨任务注意力模块设计（核心创新点）
- **代码位置**：类 `CrossTaskAttention`（`train_multitask_model.py` 与 `inference_utils.py`）
- **工作原理**：
  1. 将共享特征（维度 1280）分别投影到病害查询向量和严重程度查询向量（维度 256）
  2. 分别计算病害注意力权重和严重程度注意力权重
  3. 使用注意力权重对共享特征重新加权，得到任务专属特征
- **作用**：让病害分类和严重程度分级共享底层特征的同时，通过注意力机制实现任务间的特征增强

#### 4.4 多任务输出头设计
- **病害分类头**：`Linear(256→128) → ReLU → Dropout(0.2) → Linear(128→num_diseases)`，Softmax 激活
- **严重程度分级头**：同上结构，输出维度 3（健康 / 一般 / 严重），Softmax 激活
- **风险评分计算方法**（`scripts/risk_score.py`）：
  ```
  risk = (1 - sum(健康类概率)) × 100   # 若有健康类
  risk = top_conf × 100                # 若无健康类
  ```
  最终分档：高风险（严重程度≥2 且置信度>80%）、中风险（严重程度≥1 且置信度>70%）、低风险（常规管理）

#### 4.5 损失函数与优化器
- **多任务损失函数**：
  ```python
  loss = 1.0 × CrossEntropy(disease_output, disease_labels) 
       + 0.8 × CrossEntropy(severity_output, severity_labels)
  ```
  - 疾病分类任务权重为 1.0，严重程度分级任务权重为 0.8
  - 权重设置理由：主要任务（疾病分类）需更高权重确保精度，次要任务辅助学习
- **优化器**：AdamW（lr=5e-4, weight_decay=1e-4），相比 Adam 具有更好的权重衰减正则化
- **学习率调度**：`ReduceLROnPlateau(patience=3, factor=0.5)`，验证损失停滞时自动降学习率

#### 4.6 模型训练流程
- **训练环境**：Python 3.9+ / PyTorch 2.0+ / CUDA（CPU 亦可运行）
- **训练参数**：
  | 参数 | 值 |
  |------|-----|
  | 批次大小 (batch_size) | 32 |
  | 训练轮次 (epochs) | 15（可扩展至 30） |
  | 早停策略 (patience) | 5 |
  | 图像尺寸 | 128×128 |
  | 数据增强 | 随机翻转 + 旋转 + 亮度调整 |
- **训练命令**：
  ```bash

  python train_multitask_model.py --dataset-mode public --data-dir data/plantvillage --epochs 15 --patience 5
  
  # 模拟数据模式（快速验证）
  ```

- 健康叶片的热力分布均匀，无明显高响应区域

#### 5.6 错误案例分析
- **相似病害混淆**：如柑桔黄化（一般）与柑桔黄化（严重），视觉特征相近导致误判
- **光照影响**：强光/弱光环境下叶片颜色失真，影响模型判断
- **叶片遮挡**：多叶片重叠或叶片边缘不完整时，特征提取受限
