支持哪些作物和病虫害？

当前内置知识库覆盖 60+ 种作物健康状态与常见病害（苹果、樱桃、玉米、葡萄、番茄、马铃薯等），含可执行用药与复查建议；模型可扩展至 PlantVillage 61 类。点击首页「病害库」可按作物筛选并查看完整防治方案。

上传图片有什么限制？

支持 JPG / PNG / BMP / GIF / TIFF / WEBP，单张最大 10MB。建议拍摄清晰的叶片正面或病斑特写，避免模糊和强烈反光。

如何使用？需要几步？

四步即可：① 上传图片 → ② 预览确认 → ③ 点击「开始识别」→ ④ 查看防治方案与报告。首页顶部有步骤引导图。

识别结果可以导出吗？

可以。识别完成后支持复制摘要、下载标注结果图、导出 JSON 报告，系统自动生成 PDF 诊断报告。

如何保证识别准确率？

基于 MobileNetV2 多任务深度学习模型，验证集 Top-1 约 74.7%。可开启 MC Dropout 不确定性分析；置信度低时建议人工复核。

可以集成到其他系统吗？

提供 REST API（批量预测、病害列表、演示数据等），详见 API 文档 页面。
