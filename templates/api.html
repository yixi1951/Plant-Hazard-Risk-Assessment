GET /api/dashboard_stats

返回概览统计、与筛选条件一致的趋势图数据（chart_data），以及 ECharts 用的 visualization 聚合对象。

查询参数

参数取值说明
daysall（默认）、7、30仅统计 generated_at 在最近 N 天内的报告
sourceall、real、demo全部 / 仅真实识别 / 仅演示（demo=true 或文件名 demo_*）
 
curl "http://localhost:7860/api/dashboard_stats?days=7&source=demo"

响应片段：

{
  "filter_days": 7,
  "filter_source": "demo",
  "filtered_report_count": 7,
  "chart_data": {
    "labels": ["6/8", "6/9", "..."],
    "risk": [82, 58, ...],
    "suggestion": [...],
    "confidence": [...]
  },
  "visualization": {
    "report_count": 7,
    "severity_pie": [...],
    "disease_top": [...],
    "summary": { "avg_risk": 52.1, "avg_confidence": 90.2, "high_risk_count": 2 }
  }
}

POST /batch_predict

表单字段：batch_images（多文件）、batch_zip（ZIP）；可选 save_reports=1 将每条成功识别写入 reports/（标准 JSON schema）。

curl -X POST http://localhost:7860/batch_predict \
  -F "batch_images=@leaf1.jpg" \
  -F "batch_images=@leaf2.jpg" \
  -F "save_reports=1"

响应字段：

  • results[] — 每项含 disease_name、severity、risk_score、confidence、urgency 或 error
  • batch_visualization — 本次批量的图表数据（成功/失败、风险区间、病种 Top、严重程度）
  • batch_id、reports_saved

Web 端批量完成后可导出 CSV / JSON / 批量图表 PNG。

报告 JSON 字段（schema v1）

见 scripts/report_schema.py。顶层：schema_version、generated_at、demo、source、summary、probabilities、meta、treatment_plan；批量可选 batch_id、input_filename。

meta 建议字段：disease_name、crop、severity、disease_risk_percent、severity_confidence、urgency — 供仪表盘筛选与聚合。

更多说明见项目 README.md「仪表盘与数据可视化」「模型架构」章节。
